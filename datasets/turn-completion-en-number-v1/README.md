records the pinned prompt and plan, 121 accepted dialogues, and estimated
spend of $0.329406. Benchmark material stayed on Vast and was used only
for a private overlap screen. The screen rejected no pairs.

planned. The deterministic assignment used accepted training candidates
of the same hold length bin, shift length bin, preceding-turn form, and
continuation type. Neither the training row layout nor the position-wise
loss weights changed. Separate scenario families supplied 21 validation
and 16 test dialogues. The original hold/shift benchmark is unchanged.
