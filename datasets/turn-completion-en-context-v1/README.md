# English context-contrast pilot

Gemini 3.8 Flash generated 160 fictional telephone dialogue pairs in eight
scenario families. Each pair has the same visible caller text under two
different preceding questions. Contrast pairs contain a hold and a shift.
Invariant pairs contain two holds. The follow-up lines provide synthetic
outcome evidence and are excluded from model input.

The versioned receipt pins the generation plan, prompt and dialogue bytes.
The exporter holds out the community choir and produce box families and
uses the other six for the training supplement. The matched replay arm
repeats existing synthetic rows with the same labels and counts. The
Vast-only exporter checks the original dialogues against staged benchmark
development inputs before training. These data contain fictional examples.
